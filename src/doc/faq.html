常见问题

Q：框架是否免费使用？

框架提供免费版本和商业授权版本。免费版本可用于个人学习和非商业项目；商业项目需要购买商业授权。

Q：是否支持 MongoDB？

支持。框架内置 MySQL 和 MongoDB 双驱动 ORM，可在配置文件中灵活切换或混合使用。详见模型与数据库章节。

Q：如何进行版本升级？

通过 Composer 更新即可：

bash composer update xqkeji/framework
php xqkeji migrate:run
升级前请务必备份数据库和配置文件，并在测试环境验证后再部署到生产环境。

Q：如何部署到生产环境？

请参考安装部署文档，主要步骤包括：

  1. 设置 APP_ENV=production 和 APP_DEBUG=false
  2. 配置 Web 服务器（Nginx/Apache）
  3. 执行数据库迁移
  4. 设置目录权限（storage、cache 等目录需可写）

Q：框架支持哪些 PHP 版本？

框架最低支持 PHP 7.4，推荐使用 PHP 8.1 及以上版本以获得更好的性能和特性支持。

Q：如何自定义模块？

框架采用模块化设计，您可以：

  • 使用命令行创建模块骨架：php xqkeji make:module MyModule
  • 在 app/Module 目录下开发自定义模块
  • 参考内置模块了解模块结构

Q：遇到问题如何获取帮助？

您可以通过以下方式获取技术支持：

  • 提交技术服务，我们将在 24 小时内响应
  • 查阅框架文档与示例代码
  • 联系我们的技术团队获取一对一支持
