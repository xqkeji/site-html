快速开始

本节将带你快速创建一个简单的文章管理功能，了解框架的基本开发流程。

目录结构

框架遵循标准的 MVC 目录结构：

目录 myapp/
├── app/
│   ├── Controller/    # 控制器
│   ├── Model/          # 数据模型
│   └── View/           # 视图模板
├── route/           # 路由定义
└── public/          # Web 入口

第一步：创建控制器

创建 app/Controller/ArticleController.php：

php namespace App\Controller;

use Xqkeji\Controller;
use App\Model\Article;

class ArticleController extends Controller
{
    /** 文章列表 */
    public function index()
    {
        $list = Article::where('status', 1)
            ->orderBy('id', 'desc')
            ->paginate(10);

        return $this->view('article/index', [
            'list' => $list
        ]);
    }
}

第二步：定义路由

在 route/web.php 中添加路由：

php $router->get('/article', 'ArticleController@index');
$router->get('/article/{id}', 'ArticleController@show');
$router->post('/article', 'ArticleController@store');

第三步：创建视图

创建 app/View/article/index.html：

html {extends 'layout/main'}

{block content}
<h1>文章列表</h1>
{foreach $list as $item}
<div class="article-item">
  <a href="/article/{$item.id}">{$item.title}</a>
</div>
{/foreach}
{/block}

第四步：创建模型

创建 app/Model/Article.php：

php namespace App\Model;

use Xqkeji\Model;

class Article extends Model
{
    protected $table = 'articles';
    protected $fillable = ['title', 'content', 'status'];
}

第五步：创建数据表

执行数据库迁移：

bash php xqkeji make:migration create_articles_table

编辑生成的迁移文件：

php public function up()
{
    Schema::create('articles', function ($table) {
        $table->id();
        $table->string('title');
        $table->text('content');
        $table->tinyInteger('status')->default(1);
        $table->timestamps();
    });
}

运行迁移：

bash php xqkeji migrate:run

完成！

访问 http://yourdomain.com/article 即可查看文章列表。

恭喜！你已经完成了第一个功能的开发。接下来可以深入学习路由系统、控制器、模型等核心组件。
