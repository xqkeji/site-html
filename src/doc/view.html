模板语法

视图文件位于 app/View 目录，使用简洁的模板引擎语法。

输出变量

html <!-- 输出变量（自动转义） -->
{$name}

<!-- 输出变量（不转义） -->
{$content|raw}

<!-- 输出带默认值 -->
{$title|default='默认标题'}

条件判断

html {if $user}
    <p>欢迎，{$user.name}</p>
{else}
    <p>请登录</p>
{/if}

循环遍历

html {foreach $list as $item}
    <div>{$item.title}</div>
{/foreach}

<!-- 带索引的循环 -->
{foreach $list as $index => $item}
    <div>{$index}. {$item.title}</div>
{/foreach}

模板继承

模板继承是组织视图的核心方式，类似于面向对象中的类继承。

定义布局模板

html <!-- app/View/layout/main.html -->
<!DOCTYPE html>
<html>
<head>
    <title>{block title}默认标题{/block}</title>
</head>
<body>
    {block content}{/block}
</body>
</html>

继承布局

html <!-- app/View/article/index.html -->
{extends 'layout/main'}

{block title}文章列表{/block}

{block content}
    <h1>文章列表</h1>
    {foreach $list as $item}
        <div>{$item.title}</div>
    {/foreach}
{/block}

模板包含

使用 include 引入子模板，实现视图复用。

包含子模板

html <!-- 引入导航栏 -->
{include 'partial/navbar'}

<!-- 引入侧边栏并传参 -->
{include 'partial/sidebar' ['menus' => $menus]}
模板引擎会自动缓存编译后的 PHP 代码，生产环境下无需额外配置即可享受高性能。
