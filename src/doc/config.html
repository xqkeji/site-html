环境配置

框架使用 .env 文件管理环境变量，支持多环境切换。

基础配置项

配置项 说明 默认值
APP_NAME 应用名称 新齐程序实践
APP_ENV 运行环境 (local/production) production
APP_DEBUG 调试模式 (true/false) false
APP_URL 应用访问地址 http://localhost
APP_KEY 应用密钥（自动生成） -

数据库配置

支持 MySQL 和 MongoDB 双驱动配置。

MySQL 配置

env DB_DRIVER=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=xqkeji_db
DB_USER=root
DB_PASS=your_password
DB_CHARSET=utf8mb4
DB_COLLATION=utf8mb4_unicode_ci

MongoDB 配置

env MONGO_HOST=127.0.0.1
MONGO_PORT=27017
MONGO_NAME=xqkeji_db
MONGO_USER=
MONGO_PASS=

缓存配置

框架支持多种缓存驱动。

缓存驱动

驱动 说明 配置项
file 文件缓存（默认） 无需额外配置
redis Redis 缓存 REDIS_HOST, REDIS_PORT
memcached Memcached 缓存 MEMCACHED_HOST, MEMCACHED_PORT

Redis 配置

env CACHE_DRIVER=redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=
生产环境建议使用 Redis 或 Memcached 作为缓存驱动，性能优于文件缓存。
