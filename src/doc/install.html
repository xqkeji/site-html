环境要求

组件 最低版本 推荐版本 说明
PHP 7.4 8.1+ 需开启 pdo、mbstring、curl 扩展
MySQL 5.7 8.0+ InnoDB 引擎
MongoDB 4.0 6.0+ 可选，用于日志与缓存
Nginx / Apache - Nginx 1.20+ 推荐 Nginx + PHP-FPM
Composer 2.0 2.5+ 依赖管理工具

Composer 安装

通过 Composer 创建新项目：

bash # 创建新项目
composer create-project xqkeji/framework myapp

# 进入项目目录
cd myapp
Composer 会自动下载框架及其依赖包，并生成 vendor 目录。

配置数据库

复制环境配置文件并修改数据库连接信息：

bash cp .env.example .env

编辑 .env 文件：

env APP_NAME="新齐程序实践"
APP_ENV=production
APP_DEBUG=false

DB_DRIVER=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=xqkeji_db
DB_USER=root
DB_PASS=your_password
生产环境请务必设置 APP_DEBUG=false，避免敏感信息泄露。

初始化数据库

bash php xqkeji migrate:run

该命令会自动创建基础表结构和初始数据。

Nginx 配置

配置 Nginx 虚拟主机：

nginx server {
    listen 80;
    server_name yourdomain.com;
    root /path/to/myapp/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass 127.0.0.1:9000;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}

Apache 配置

如果使用 Apache，确保启用 mod_rewrite 模块：

apache <VirtualHost *:80>
    ServerName yourdomain.com
    DocumentRoot /path/to/myapp/public

    <Directory /path/to/myapp/public>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>

验证安装

访问 http://yourdomain.com，看到欢迎页面即表示安装成功。

如果遇到问题，请检查 PHP 错误日志和 Web 服务器日志，或提交技术咨询获取帮助。
