基础路由

路由文件位于 route/web.php，所有路由都在此文件中定义。

基本路由定义

php use Xqkeji\Router;

$router->get('/user', 'UserController@index');
$router->post('/user', 'UserController@store');
$router->put('/user/{id}', 'UserController@update');
$router->delete('/user/{id}', 'UserController@delete');

路由参数

路由参数使用 {参数名} 语法定义：

必选参数

php $router->get('/user/{id}', 'UserController@show');

可选参数

php $router->get('/user/{id?}', 'UserController@show');

参数约束

php $router->get('/user/{id}', 'UserController@show')
    ->where('id', '[0-9]+');

中间件

中间件用于在请求到达控制器之前进行过滤和处理。

创建中间件

php namespace App\Middleware;

use Xqkeji\Middleware;

class AuthMiddleware extends Middleware
{
    public function handle($request, $next)
    {
        if (!$request->user()) {
            return redirect('/login');
        }

        return $next($request);
    }
}

应用中间件

php $router->get('/dashboard', 'DashboardController@index')
    ->middleware('auth');

路由分组

路由分组用于批量应用中间件、前缀等属性。

基础分组

php $router->group(['prefix' => '/admin'], function ($router) {
    $router->get('/dashboard', 'AdminController@dashboard');
    $router->get('/users', 'AdminController@users');
});

带中间件的分组

php $router->group([
    'prefix' => '/admin',
    'middleware' => ['auth', 'admin']
], function ($router) {
    $router->get('/dashboard', 'AdminController@dashboard');
});

命名路由

php $router->get('/user/profile', 'UserController@profile')
    ->name('user.profile');

// 生成 URL
$url = route('user.profile');
命名路由可以方便地生成 URL，避免硬编码路由路径。
