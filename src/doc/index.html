框架概述

新齐低代码开发框架是一套基于 PHP 的高性能、高效率 Web 开发框架，采用 MVC 架构设计，内置丰富的功能组件和代码生成工具，帮助开发者快速构建企业级应用系统。

本框架适用于企业官网、电商系统、后台管理、CRM、ERP 等多种业务场景，支持模块化扩展与灵活配置。

核心特性

  • MVC 架构：清晰的模型-视图-控制器分层设计，代码结构规范
  • ORM 数据库操作：支持 MySQL / MongoDB，链式调用，自动映射
  • 路由系统：RESTful 路由、中间件、分组路由，URL 对 SEO 友好
  • 模板引擎：简洁的模板语法，支持继承、包含、条件判断
  • 权限管理：基于 RBAC 的细粒度权限控制
  • 代码生成器：一键生成 CRUD 代码，大幅降低重复劳动
  • 模块化设计：功能模块可独立安装、卸载、升级
  • 多环境配置：开发、测试、生产环境一键切换

技术栈

组件 技术选型 说明
后端语言 PHP 7.4+ 推荐 PHP 8.1+，性能更优
数据库 MySQL / MongoDB 双驱动 ORM，灵活切换
Web 服务器 Nginx / Apache 推荐 Nginx + PHP-FPM
依赖管理 Composer PHP 包管理工具
模板引擎 自研模板引擎 轻量级，语法简洁

设计理念

框架遵循以下设计原则：

  • 约定优于配置：合理的默认值，减少配置项
  • 开箱即用：内置常用功能，快速启动项目
  • 高度可扩展：模块化设计，按需加载
  • 性能优先：缓存机制、延迟加载、代码优化
  • 安全可靠：SQL 注入防护、XSS 过滤、CSRF 保护
