内置模块

框架提供丰富的内置模块，开箱即用，支持热插拔。

用户管理模块 (user)

提供完整的用户注册、登录、个人中心功能。

  • 用户注册与登录（支持邮箱/手机号）
  • 密码找回与重置
  • 个人中心与资料编辑
  • 会员等级与积分系统
  • 第三方登录集成（微信、QQ）
bash php xqkeji module:install user

权限管理模块 (auth)

基于 RBAC 的细粒度权限控制系统。

  • 角色管理（创建、编辑、删除）
  • 权限节点管理
  • 菜单权限控制
  • 操作日志记录
  • 数据权限隔离
bash php xqkeji module:install auth

内容管理模块 (cms)

灵活的内容管理系统，支持文章、分类、标签。

  • 文章发布与编辑（富文本编辑器）
  • 分类管理（多级分类）
  • 标签管理
  • 评论系统
  • SEO 优化
bash php xqkeji module:install cms

商城系统模块 (shop)

完整的电商解决方案。

  • 商品管理（SKU、库存、价格）
  • 订单管理（下单、支付、发货）
  • 支付集成（支付宝、微信支付）
  • 物流跟踪
  • 优惠券与促销活动
bash php xqkeji module:install shop

图片管理模块 (media)

统一的文件与图片管理。

  • 文件上传（支持拖拽上传）
  • 图片缩略图自动生成
  • 相册管理
  • 云存储集成（阿里云 OSS、七牛云）
bash php xqkeji module:install media

代码生成模块 (codegen)

根据数据表自动生成 CRUD 代码，大幅提升开发效率。

  • 根据数据表生成模型
  • 生成控制器与路由
  • 生成视图模板
  • 支持自定义模板
bash php xqkeji module:install codegen
所有模块均采用热插拔设计，安装后自动注册路由与菜单，卸载时自动清理，不影响系统运行。
