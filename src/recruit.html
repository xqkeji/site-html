PHP 全栈开发实习工程师

工作地点 清远高新区
实习周期 最少 3 个月
实习补贴 首月 1500 元/月，月度考核合格次月起调整为 1800 元/月

岗位说明

本岗位为跟岗学习型实习，面向广东省职教城全日制在校高职计算机相关专业学生，由创始人一对一技术带教，开放真实商业项目源码学习，循序渐进参与代码练习与功能开发。

拒绝单纯打杂，不安排机械性重复工作，以技术成长为核心目标。

岗位职责

  1. 学习并研读公司 PHP 项目源码，理解整体架构与业务逻辑；
  2. 在指导下完成功能模块练习开发，参与代码调试与问题排查；
  3. 协助进行功能测试、文档整理与基础数据维护；
  4. 按阶段完成学习任务，提交学习总结与代码作业。

任职要求

  1. 全日制高职在校未毕业学生，计算机相关专业；
  2. 掌握 PHP 基础语法，了解 MySQL 基本操作；
  3. 了解 HTML/CSS/JavaScript，有简单 Web 开发练习经验优先；
  4. 具备自主查阅文档、独立思考解决问题的能力；
  5. 学习态度端正，能保证连续实习至少 3 个月；
  6. 已取得毕业证人员请勿投递。

你将获得

  • 创始人一对一技术指导，固定答疑时段，系统学习 PHP 全栈开发；
  • 开放真实商业项目源码，接触完整项目架构与生产环境；
  • 循序渐进的任务体系，从阅读源码到独立开发练习模块；
  • 实习期满表现优异者，可洽谈长期合作或转正机会；
  • 统一购买商业实习意外险。

投递说明

  • 请在线填写应聘信息并提交；
  • 面试包含基础技术笔试，零基础请勿投递；
  • 实习补贴按月足额发放，未满整月按实际出勤折算；
  • 本岗位为学习型实习，不属于劳动关系，不缴纳社保。
重要提示：本岗位仅限在校未毕业学生投递；仅短期 1–2 个月换取实习证明的人员请勿投递。
